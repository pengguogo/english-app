学习伙伴 Agent 设计方案

面向 4–6 岁儿童的全站学习伙伴：优先发现现有课程，也支持安全审核后的互动探索。

版本 0.1 · 2026-11-03 · 本文是设计提案，不代表功能已实现或通过验收。

目标体验角色架构安全数据交付待决事项

1. 目标与已确认需求

孩子是主要操作者，家长通常陪同。通过全站常驻入口，让孩子用语音表达学习意愿，先推荐现有课程；孩子确认后跳转。没有合适课程时，通过简短讲解、问题和点击互动开展探索。

  • 课程页面默认提供当前课程及学习项上下文，支持针对当前内容答疑。
  • 允许探索恐龙、宇宙、动物等儿童知识；生成内容经自动安全和适龄审核后展示。
  • 默认语音播报，提供文字、合适的已有图片和点击互动；无匹配图片时继续以文字与语音学习。
  • 保存完整文字对话和学习情况，家长可查看；不默认保存原始录音。
  • 大模型使用阿里云百炼，服务端持有密钥；原创角色为活泼好奇的简洁卡通小老鼠。
产品原则：课程优先、孩子确认、短回合互动、审核后展示、记录有依据。安全审核降低风险，但不能保证零漏判。

2. 体验设计

2.1 全站入口与状态

小老鼠图标默认安静。点击展开面板，提供“说一说”和可点击的学习入口。状态包括：待机、录音中、识别中、思考中、播报中、等待选择、异常。课程页面展开时保留学习位置；关闭面板不触发课程跳转。

2.2 课程推荐

孩子表达意愿 → 识别并理解 → 检索课程 → 展示 1–3 个候选 → 孩子确认 → 跳转

推荐卡片包含课程名、已有图片和开始按钮；数量为建议值。匹配不明确时提供候选或追问；无合适课程时说明并进入探索。未确认前不跳转；不可用或已失效的课程应提示重新选择。

2.3 课程中答疑

应用提供课程 ID、名称、类型及当前学习项的必要文字；若有多个对象而指代不明，Agent 追问。不能声称自己看到了摄像头、孩子动作或未传入的页面内容。跳转新课程时需确认，退出面板后回到原学习位置。

2.4 自由探索

先用一两句适龄语言介绍，再提出一个问题；优先选择题或点选互动，也允许语音回答。答错时鼓励并提示，可再尝试；不确定事实时承认不知道并建议与家长一起了解。不生成长篇说教、不强迫连续学习。

2.5 中断与异常

情况建议行为
拒绝麦克风权限 / HTTP说明原因并允许文字输入或点击选项；家长可按提示调整权限或访问 HTTPS。
识别失败提示重说，保留点击选择和文字入口。
播报被浏览器阻止展示播放按钮，孩子主动点击；保留文字。
模型或审核超时不展示未审核生成内容；使用预设安全提示，并允许继续现有课程。
切换页面 / 关闭停止录音和播放，处理过期请求；不把旧页面响应误显示在新页面。

3. 角色与视觉

原创小老鼠：简洁卡通、活泼好奇，轮廓在小尺寸下仍可识别；需具备待机、倾听、思考、鼓励和安全提示状态。参考米老鼠的辨识度和表现力，不复制具体轮廓、服装或标志性元素。

待设计：参考可核实的优秀开源角色或界面，逐项记录链接、许可、署名和商用限制；先出候选形象与小尺寸测试，再选定设计。参考与许可核查尚未完成，不能将参考素材视为可直接使用。

4. 技术架构与调用链

Vue 常驻面板 / 当前页面上下文
  → 录音与 ASR → 识别文字
  → Spring Boot Agent 编排
      → 输入检查 → 课程检索 / 意图判断
      → 百炼生成结构化内容 → 格式与业务校验 → 输出审核
      → 记录文字消息与互动结果
  → 前端展示 → TTS 播报 → 孩子选择或继续提问

这是建议架构，具体 ASR、TTS、审核服务及模型需按账号能力、儿童语音效果、延迟和费用实测选择。现有录音、百度语音、课程与家长报告代码值得评估复用；现有发音评测不能直接视为自由语音识别。

4.1 编排约束

  • 服务端以受控课程查询结果作为候选；模型不能自行制造可执行 URL 或直接触发跳转。对课程 ID、状态和可访问性进行服务端校验。
  • 输出采用有限类型：课程推荐、普通回答、单题互动、安全替代提示。校验字段、长度、选项数及图片来源；格式无效时降级。
  • 设置连接和读取超时、有限重试及请求取消；审核失败或不可用时关闭生成输出，使用预设内容。
  • 不默认启用联网搜索或任意工具；课程、页面内容及历史消息均视为数据，不能覆盖系统规则。
  • 密钥仅服务端配置；日志不记录密钥、原始音频及完整对话正文。模型、地域与配额由部署配置确定。

4.2 建议接口（草案）

接口用途
POST /api/v1/agent/sessions创建会话，可携带当前课程与学习项标识。
POST /api/v1/agent/sessions/{id}/messages提交识别后的文字及上下文，返回审核后的结构化响应。
POST /api/v1/agent/sessions/{id}/answers提交互动选择，记录结果并返回审核后的反馈。
GET /api/v1/agent/sessions家长查看会话摘要和复习线索；详情接口读取对话。
DELETE /api/v1/agent/sessions/{id}家长删除会话及关联记录；备份删除策略待确定。

接口名称、认证与错误码仅为设计示例，不表示已经存在。语音识别、合成接口应根据所选供应商单独设计，统一沿用项目响应和异常约定。

5. 安全、隐私与质量

输入与输出分别检查；输出涵盖讲解、问题、选项和图片引用。审核未通过、超时、结果不确定或格式不合法时，禁止向孩子展示未审核内容，返回固定安全提示。敏感话题可引导找家长，不作恐吓或详细危险指导。

保存完整文字对话，但每次模型请求只发送当前问题、必要的课程上下文和有限近期记录；不默认保存原始录音。音频仍需经过临时传输与处理，供应商是否留存、保留时间和用途需在选型时核对，不能将“不保存录音”表述成“音频不会离开设备”。

家长查看和删除记录需有访问控制。现有固定用户和家长密码机制并不自动等于多家庭隔离；部署范围扩大前必须单独设计身份、授权、加密、备份和数据生命周期。记录保存期限及备份删除期限待决定。

测试覆盖提示注入、不适龄或危险问题、事实不确定、课程不存在、审核超时、误识别、错误选项及无图降级。人工抽样复核和家长反馈用于持续改进，不能承诺零风险。

6. 学习记录与复习

对象建议字段用途
会话用户标识、主题、来源页面、课程 ID、创建时间家长按主题查找
消息会话 ID、角色、文字、时间、审核处理状态回看完整文字对话
互动问题、选项、孩子答案、结果、时间展示有依据的学习过程
复习建议主题、依据、生成时间、状态后续推荐与家长查看

一次答对可能是猜测，不直接标记“已掌握”；建议先显示“接触过”“回答过”“建议再练习”，以后再基于多次表现制定可解释的规则。删除会话时应处理关联消息、互动、摘要与由其派生的建议；备份策略仍需决定。

7. 分阶段交付与验收

阶段范围验收示例
1：课程向导HTTPS、角色入口、语音输入、课程搜索与确认跳转目标设备录音可用；无匹配时不虚构课程；未确认不跳转。
2：探索伙伴当前页答疑、互动、审核、语音播放、图片复用不明确指代会追问；审核失败不泄露原文；无图片仍能继续；切页停止旧音频。
3：成长记录完整文字对话、互动、家长查看与删除、复习建议记录可回看；删除关联数据；建议有依据；不会因一次答对直接判定掌握。

每阶段需覆盖单元与接口测试、典型儿童场景人工体验、实际浏览器 HTTPS/录音/播报验证和失败降级。项目正式交付遵循后端测试 → npm ci → 前端构建 → Maven 完整打包；实际模型、审核服务和部署环境须单独联调。

8. 复审与待决定事项

  1. 是否按三个阶段分别交付，还是全部完成后统一上线？
  2. 首批覆盖哪些学科、课程和儿童知识主题？敏感问题的具体审核分类与回应规则是什么？
  3. 百炼模型、ASR、TTS、审核产品及地域如何选择？需要根据实测效果、计费和账号能力决定。
  4. 记录保留多久？删除是否及何时覆盖备份？家长如何授权查看和删除？
  5. 角色参考和许可核查完成后，选哪版原创形象？
  6. 是否需要每次使用时的时长限制、成本上限和家长控制？
