# 孩子成长档案

首页「成长档案」入口供家长记录孩子资料、身高体重和成长照片。年龄由生日在前端按
当前日期计算，不存入数据库。测量日期和照片日期默认当天，可以补录历史日期；身高
与体重可分别填写，轨迹图仅使用已填写的测量值。照片的日期与说明可修改；更换图片
时删除旧照片并重新上传。

## 存储

- 档案继续使用固定 `app_user.id=1`；测量历史存 `growth_measurement`；照片元数据
  存 `child_photo`。结构由 V78、V79 Flyway 迁移创建。
- 照片原文件不进入数据库或 JAR，上传后重新编码为 JPG/PNG，保存在
  `CHILD_PHOTO_DIR` 指定的磁盘目录，默认是启动目录下的 `child-photos/`。
  该目录必须可写、持久化，并与 `english.db` 一起备份和迁移。
- 照片限制 8 MB，接口只通过记录 ID 读取，不接受客户端提供文件路径。

## 访问

启动服务前设置 `CHILD_GROWTH_ACCESS_KEY` 为自定义强口令。未设置时成长档案接口
返回 503。页面会要求家长输入口令，并仅在当前浏览会话中保存；照片读取也使用
同一口令。生产部署应使用 HTTPS，以免口令和照片在网络传输中暴露。

```bash
export CHILD_GROWTH_ACCESS_KEY='自定义的长随机口令'
export CHILD_PHOTO_DIR='/持久化目录/child-photos'
```
