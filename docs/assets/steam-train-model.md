# 蒸汽火车 3D 模型

- 创建日期：2026-09-08。
- 入口：首页「探索 3D 模型」，应用路由 `/models`，部署路径 `/app/models`。
- 来源：本项目用 Three.js 基础几何体原创组合建模，无外部模型、贴图或热链素材。
- 定位：儿童友好的风格化展示模型，不对应特定型号，比例与机械细节经过简化。
- 内容：锅炉、烟囱、驾驶室、辐条车轮、连杆、前照灯、煤水车及轨道。

## 实现与扩展

`frontend/src/components/models/steamTrain.js` 负责模型几何结构，
`modelScene.js` 负责相机、灯光、触屏/鼠标轨道控制和资源释放，
`ModelViewer.vue` 提供操作按钮及 WebGL 失败提示。
新增其他模型时可复用展示器与场景控制，将模型工厂独立为新的文件。
材质色统一读取 `frontend/src/styles/tokens.css` 的 `--model-*` 令牌。

模型按路由懒加载，与应用一起打包，不依赖运行时 CDN。
仅在操作及容器尺寸变化时重绘，离开页面会释放几何体、材质、阴影贴图、控制器与渲染器。
此模块为独立展示功能，不新增课型或修改课程数据。

## 操作验收

- 首页进入模型馆，返回按钮回到首页。
- 桌面拖动与滚轮、移动端单指旋转与双指缩放。
- 侧面、正面、俯视、放大、缩小、复位视角。
- 桌面和窄屏布局、刷新直接进入 `/app/models`。
- 无 WebGL 或上下文中断时，显示说明并提供重新加载按钮。
