# 6 岁儿童游戏补充

- 日期：2026-09-28
- 新增：动物翻翻乐（4 对 / 6 对）、图案接龙（AB / AAB / ABC）、亲子井字棋（本地双人）。
- 选择理由：规则短、无需拖动或键盘、没有倒计时惩罚，提供明确的完成反馈。年龄定位为产品设计判断，实际难度可由家长陪玩确认。
- 玩法参考：经典记忆配对玩法，参考 https://github.com/kubowania/memory-game 的玩法说明；未复制其代码或素材。
- 实现：本站原创 Vue 组件，不引入第三方游戏依赖、广告、注册或远程资源。图案使用系统 emoji，作为游戏符号，不属于课程学习项。
- 入口：游戏专区与三个独立路由；沿用现有每日学习 5 分钟 / 家长密码解锁机制。
- 无新增课程、数据库迁移或素材下载。

## 验证

- 后端 63 项测试、前端 33 项测试（含新增游戏逻辑 4 项）、前端生产构建及 Maven 完整打包通过。
- 使用独立临时 SQLite 数据库启动生产 JAR，验证学习门槛与解锁后的游戏入口。
- 页面操作：翻牌不匹配盖回、全部配对通关、切换 6 对重置；接龙答错重试、答对及下一题；井字棋获胜禁用落子与重新开始。
- 375px 手机视口检查三款页面，确认按钮可用、内容无横向溢出。
