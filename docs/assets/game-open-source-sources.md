# 游戏专区开源组件来源

## 中国飞行棋

- 项目：Chinese Ludo
- 来源：https://github.com/netmanfisher/chinese-ludo
- 许可证：MIT
- 引入日期：2026-09-27
- 本地位置：`frontend/public/vendor/chinese-ludo/`
- 用途：完整复用棋盘、2–4 人玩法、棋子移动、飞跃与撞子动画；通过站内游戏解锁页加载。

## 围棋

- 项目：Tenuki
- 来源：https://github.com/aprescott/tenuki
- npm 版本：0.3.1
- 许可证：MIT
- 用途：提供合法落子、提子、全局同形禁着、停一手、悔棋、终局死活标记与中国数子法计分。界面继续使用本站 Vue 组件和设计令牌。

## 冒险棋设计参考

- 参考项目：https://github.com/AdheeshaRavindu/Snake-and-Ladder
- 用途：仅参考蛇梯棋的动态行进体验；没有复制该项目代码、图片或其他资产。本站实现为独立的 Vue/CSS 动画版本。
