# 燃油火车 3D 教学模型

## 交付范围

- 日期：2026-09-09。
- 原创程序化几何模型，与蒸汽火车共用 `/app/models` 模型馆；默认展示新燃油机车。
- 采用六轴柴油电力机车的外形与结构概念，并非特定制造商车型的精确复刻。
- 本地几何体生成，没有下载第三方模型、图片或纹理，也没有外部运行时素材请求。
- 配色沿用项目 `tokens.css` 中的 `--model-*` 令牌。

## 细节与操作

- 六个轮轴、轮缘、牵引电机外形、制动块、轴箱盖六角螺栓、螺旋弹簧。
- 机罩面板分缝、通风孔、铰接区域紧固件、扶手、防滑踏板与登车阶梯。
- 驾驶室雨刷、后视镜、灯组、门把手、天线与喇叭。
- 散热风扇叶片、中心轴、同心护网与侧面格栅。
- 打开机罩可查看示意柴油机：两列气缸盖、螺栓、管线和发电机外形。
- 底部燃油箱、固定箍带、加油口与管路；前后车钩、锁销、制动风管接头。
- 六个零件近景按钮与可见零件点击拾取。柴油机近景自动打开机罩；可手动关闭。
- 拖动旋转，滚轮或双指缩放，右键拖动或双指移动平移；提供放大、缩小与复位按钮。
- 静态几何按零件和材质合并，保留零件拾取边界；按需渲染，不持续运行动画循环。
