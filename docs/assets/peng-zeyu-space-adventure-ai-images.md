# 《彭泽宇的月球星种大救援》AI 配图记录

用途：个人儿童学习应用中的课外中文阅读课程。

生成日期：2026-07-29。

生成方式：使用 Codex 内置 `imagegen` 工具逐张生成，分类为
`illustration-story`。用户提供的儿童照片仅作为主角彭泽宇的身份与外貌参考；
其余人物、机器人、航天器及场景均根据本课程原创情节生成。

## 统一约束

- 横向 3:2 构图，适合阅读卡片展示。
- 明亮、温暖的高品质 3D 儿童动画电影风格，适合 5～8 岁儿童。
- 主角保持参考照片中的短黑发、圆润脸型、明亮眼睛和自然笑容。
- 地面场景穿简洁黑色小礼服；训练时穿蓝白训练服；太空场景穿白色与深蓝色儿童宇航服。
- 太空冒险中始终有成年航天员负责危险操作，不表现儿童独自执行危险任务。
- 无文字、字幕、水印、品牌标识、伤害或恐怖画面。
