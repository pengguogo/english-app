# 《彭泽宇的十个成长小任务》故事系列大纲

## 系列定位

- 适龄：5～8 岁，现实成长故事，适合亲子共读。
- 核心结构：错误选择 → 自然后果 → 发现影响 → 主动补救 → 学会方法。
- 教育原则：不恐吓、不羞辱、不强迫；大人保障安全，让孩子体验温和后果后再提问引导。
- 每篇后续可扩写为 6～8 个阅读页，并配套亲子讨论题。

## 十篇故事大纲

### 1.《没有排队的小队长》——遵守公共规则

1. 开端：彭泽宇担任科技馆参观小队长，急着带大家体验机器人。
2. 错误选择：他没有排队，也没有听完工作人员的操作规则。
3. 自然后果：机器人任务被错误启动，小组需要退出体验区重新排队，伙伴们也被耽误。
4. 发现影响：他意识到规则不只是限制自己，还保护所有人的时间和公平。
5. 主动补救：向伙伴道歉，协助工作人员恢复道具，并重新带队排好顺序。
6. 行动口诀：`先看标志，听完规则，轮到我再行动。`

### 2.《渐渐变凉的早餐》——专心、按时吃饭

1. 开端：上学前，爸爸准备了早餐，彭泽宇却边玩玩具边慢慢吃。
2. 错误选择：几次提醒后，他仍不断离开餐桌找玩具。
3. 自然后果：早餐渐渐变凉，整理书包和选择故事书的时间也被占用了。
4. 发现影响：他不是被罚掉了时间，而是自己的拖延挤走了原本想做的事情。
5. 主动补救：收起玩具，专心完成早餐，并在晚上设置“餐前玩具停车位”。
6. 行动口诀：`吃饭时只吃饭，结束后再痛快玩。`

### 3.《来不及试跑的小车》——做事拖拉

1. 开端：班级准备举办纸板小车展示，彭泽宇有一周准备时间。
2. 错误选择：他每天都说“明天再做”，直到展示前一晚才开始。
3. 自然后果：小车虽然完成了，却没时间试跑，展示时车轮突然松开。
4. 发现影响：伙伴没有嘲笑他，但他发现“做完”和“做好”之间还需要检查时间。
5. 主动补救：修好车轮、重新展示，并把任务拆成设计、制作、试跑三个小步骤。
6. 行动口诀：`先做一小步，明天少着急。`

### 4.《走不动的寻宝队员》——培养运动习惯

1. 开端：社区准备周末公园寻宝，伙伴们每天用游戏方式练习跑、跳和投掷。
2. 错误选择：彭泽宇连续几天只想坐着看动画，不愿参加任何活动。
3. 自然后果：寻宝当天，他很快疲倦，只能暂时休息，错过了一段喜欢的探索路线。
4. 发现影响：运动不是比赛惩罚，而是让身体有力气参加更多好玩的事情。
5. 主动补救：从每天十分钟的追球、骑车和亲子散步开始，逐渐找到自己喜欢的运动。
6. 行动口诀：`不必样样第一，每天动一动就有进步。`

### 5.《彩虹菜园的空白味道》——面对挑食

1. 开端：学校举行彩虹蔬菜品尝会，每个小组要完成一张味道地图。
2. 错误选择：彭泽宇只看颜色便说“不好吃”，拒绝观察、闻味或尝试。
3. 自然后果：轮到他描述绿色蔬菜时，味道地图上只能留下空白。
4. 发现影响：没有尝试就直接拒绝，会让自己失去认识新味道的机会。
5. 主动补救：从看、闻、碰、舔、尝一小口逐级探索，最后找到一种愿意再次尝试的做法。
6. 行动口诀：`可以暂时不喜欢，但先认识一下。`

### 6.《消失的图书馆徽章》——及时整理

1. 开端：彭泽宇第二天要带借阅证和图书参加阅读活动。
2. 错误选择：玩完后把衣服、图书和积木随手堆在不同地方。
3. 自然后果：早晨找不到借阅证，全家一起寻找，阅读活动的自由选书时间因此缩短。
4. 发现影响：东西不会真的消失，混乱却会偷走自己和家人的时间。
5. 主动补救：归还图书并整理房间，为书本、证件和玩具设置固定位置。
6. 行动口诀：`用完送回家，下次马上找到它。`

### 7.《打哈欠的观察员》——按时睡觉

1. 开端：第二天有自然观察活动，彭泽宇晚上却想继续看故事、搭积木。
2. 错误选择：他一次次说“再玩五分钟”，远远超过原定睡觉时间。
3. 自然后果：第二天精神不足，没听清集合要求，也错过了自己期待的鸟鸣线索。
4. 发现影响：睡觉不是结束快乐，而是在为第二天储存精力。
5. 主动补救：请老师重复要求，当晚提前完成洗漱，并设置固定的睡前收尾流程。
6. 行动口诀：`玩具也休息，我也充好电。`

### 8.《牙齿上的彩色警报》——认真刷牙

1. 开端：彭泽宇觉得刷牙麻烦，连续几次只随便刷几下。
2. 错误选择：他总说“看起来很白，不刷干净也没关系”。
3. 自然后果：口腔检查时，牙菌斑显示工具让没刷净的位置出现明显颜色，需要花更多时间清洁。
4. 发现影响：看不见污垢不代表牙齿已经干净，刷牙需要方法和时间。
5. 主动补救：在家长协助下练习按顺序刷牙，并使用两分钟计时歌。
6. 行动口诀：`早晚认真刷，里面外面都不落。`

### 9.《被平板挤走的搭建时间》——管理屏幕时间

1. 开端：彭泽宇和爸爸约好晚饭后一起搭建纸箱城堡。
2. 错误选择：平板时间结束后，他仍不断要求“再看一个”，还偷偷开启下一集。
3. 自然后果：原本的城堡时间被挤掉，睡前流程也变得匆忙。
4. 发现影响：屏幕本身不是坏东西，但没有边界时会挤走运动、交流、创造和休息。
5. 主动补救：和家人共同制定屏幕计划，关闭自动播放，并准备阅读、积木和户外游戏作为替代。
6. 行动口诀：`时间到了就关闭，给别的快乐留位置。`

### 10.《谁弄坏了纸箱城堡》——正确表达情绪

1. 开端：伙伴修改了城堡设计，彭泽宇感到生气，却不肯说明原因。
2. 错误选择：他抢走材料、用力推倒一部分城墙，伙伴们不知道发生了什么。
3. 自然后果：合作暂停，城堡也需要重新搭建，大家都感到难过。
4. 发现影响：情绪没有错，但伤害东西或别人不能解决问题。
5. 主动补救：先停下、呼吸、说出“我很生气，因为……”，再和伙伴商量修复方案。
6. 行动口诀：`先停一停，说出感受，再一起想办法。`

## 内容与接口约定

- 本阶段只形成故事大纲，不修改数据库、前后端接口或课程类型。
- 后续课程化时沿用现有 `READING + QUIZ` 结构；每个阅读页和题目必须提供对应 JPG 配图。
- 新课程通过新 Flyway 迁移交付，不修改历史迁移或直接编辑数据库。
- 成人角色只负责安全边界、开放式提问和必要示范，不替主角完成补救。
- 吃饭故事不要求吃完固定分量；挑食故事不强迫尝试、不用甜食奖励。该处理遵循美国儿科学会关于规律进餐、减少干扰、反复温和提供新食物的
  [建议](https://www.healthychildren.org/English/tips-tools/ask-the-pediatrician/Pages/How-Do-I-Help-My-Picky-Eater-Try-More-Foods.aspx/1000)。
- 运动采用有趣、多样、逐步增加的活动，不把竞技成绩作为目标，参考
  [CDC 儿童运动建议](https://www.cdc.gov/physical-activity-basics/adding-children-adolescents/index.html)。
- 屏幕故事采用家庭共同规则和无屏幕场景，不把电子设备妖魔化，参考
  [AAP 家庭媒体计划](https://www.healthychildren.org/English/family-life/Media/Pages/How-to-Make-a-Family-Media-Use-Plan.aspx)。
- 睡眠故事只表现注意力和精力方面的自然影响；6～12 岁儿童通常建议每天睡眠 9～12 小时，参考
  [CDC 睡眠建议](https://www.cdc.gov/sleep/about/index.html)。

## 验收标准

- 每篇只聚焦一个核心习惯，吃饭与挑食、吃饭拖拉与任务拖拉不重复。
- 后果必须由主角的选择自然产生，不来自家长临时追加惩罚。
- 每篇必须包含道歉、修复、重新尝试或制定工具中的至少一种补救行为。
- 不出现羞辱、威胁、强迫进食、危险模仿或“做一次就立即生病”等夸张因果。
- 结尾给出一个孩子第二天就能执行的动作或口诀，而不只停留在说教。
